MINISHELL

This project has been created as part of the 42 curriculum by "arivas-q" and "mruiz-ur".

DESCRIPTION

The project consists of building a shell similar to Bash on Linux.
Most of the basic features are implemented, such as pipes, redirections, built-ins, command history, and signal handling.
Some features, such as wildcards (*) or temporary variables, are not implemented.

INSTRUCTIONS

In the root directory, you can compile the project simply by running make. If you want to clean the generated files, run make fclean. Once compiled, you can execute the program with ./minishell.
When launched in a terminal, minishell (similar to Bash or other shells) will start and display the prompt "Prompt: ".
You can use it like a Bash terminal and test whatever you want.
You can navigate through the command history using the ↑ and ↓ arrow keys.
To exit the program, you can use the exit command or press Ctrl + D inside minishell.
